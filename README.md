## 💻 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sathvik7777/customer.git
   cd customer
   ```

2. **Create a virtual environment (recommended)**
   ```bash
   python -m venv venv
   
   # On Windows
   venv\Scripts\activate
   
   # On macOS/Linux
   source venv/bin/activate
   ```

3. **Install dependencies**
   ```bash
   pip install jupyter pandas numpy matplotlib seaborn scikit-learn
   ```

## 🚀 Usage

1. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```

2. **Open the notebook**
   - Navigate to `customer_booking.ipynb` in your browser
   - Execute cells sequentially to run the analysis
   - Modify parameters as needed for your use case

3. **Example workflow**
   - Load and inspect the data
   - Perform exploratory data analysis
   - Clean and preprocess data
   - Generate insights and visualizations
   - Create booking reports
